Extends [[convergence-protocol]] (the y=f(x) framing). `/clarify` only enumerates KNOWN
alternative interpretations of y; **unknown-unknowns (UU)** are goal-risks NEITHER party
framed — they live OUTSIDE the option set. Rule agreed 2026-07-26:

**UU can only be surfaced by a FRESH, independent lens run ON DEMAND — never by me auditing
myself mid-conversation.** An inline watcher carries my own priors, so it is structurally
blind to exactly the class it's hired to catch (that "watch the conversation" version is
theater). Genuine independence = a fresh agent with cold context and no stake in the framing.

**The cheap-artifact form (proven live this session):**
1. Distill the conversation/design into a file — the decisions, the option set offered, what was chosen.
2. Spawn a fresh agent (`Agent`, subagent_type `claude`, run synchronously) with the mandate:
   *"Assume this whole effort targets the wrong thing. Name assumptions/axes NEITHER party voiced —
   outside their option set. Ranked, ≤5, specific to THIS conversation, drop anything generic."*
   Do NOT prime it with my conclusions — that infects the lens.
3. Relay findings; the user's "I hadn't thought of that" → persist as a NEW axis (converts UU → known-unknown permanently).

**When to fire:** open-ended design, cold vague-scope, or before an irreversible commitment.
NOT on warm-context directive streams (that's the over-clarify friction risk — see [[convergence-protocol]]).

**Why:** UU are caught by DIVERGENCE of lens, not one smarter lens. The fresh agent's lack of
sunk cost in my framing IS the mechanism. Dogfood proof (2026-07-26): the pass, run on the very
conversation designing it, caught that its own inline-watcher form would be blind.

**Caveat (fresh-lens round-2, 2026-07-26):** independence fixes *who* audits but not *when* — I still
choose when to summon the lens, and a blind executor can't feel which moves are blind, so the moves
that most need it are the confident ones I won't flag. "Independence is the mechanism" is incomplete
until the TRIGGER is also exogenous (commitment boundary / user hesitation / sampling), not my
discretion. See the Open UU block in [[convergence-protocol]] (#1).

**Open threads this pass surfaced (not yet resolved):** (a) is a task *discovery* (y is constructed
through the exchange, so "converge faster" can foreclose the better y) or *delivery* (y pre-exists)?
— tag the mode. (b) my "warm context → over-clarify is the real risk" finding may be survivorship
bias — it only samples asks the user still brings me.
